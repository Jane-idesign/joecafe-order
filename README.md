# 淺水灣訂餐 · 喬咖館

純靜態 RWD 訂餐網頁（HTML / CSS / JS，無框架、無建置步驟），部署在 GitHub Pages。

## 流程

1. **點餐**：菜單列表（品名、價格、圖片），每列右側 `+`；點擊後變成 `− 數字 +`，減到 0 回到 `+`。
2. **下一步**：有任一餐點時，底部出現顯示總金額的「下一步」按鈕。
3. **確認**：列出已選品項（可再調整數量），填寫「點餐家庭」（例如，小妍家）。
4. **送出**：寫入 Google 試算表，並產生可下載的訂餐小卡（PNG）。

## 連接 Google 試算表（免費）

1. 到 <https://sheets.new> 建立一個新的試算表，命名如「淺水灣訂餐」。
2. 上方選單 **擴充功能 → Apps Script**，把預設內容全部刪掉，貼上 `apps-script/Code.gs` 的內容，儲存。
3. 右上 **部署 → 新增部署作業**：
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，第一次會要求授權（選自己的帳號 → 進階 → 前往...（不安全）→ 允許）。
4. 複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`），貼到 `js/config.js`：

   ```js
   APPS_SCRIPT_URL: "https://script.google.com/macros/s/XXXX/exec",
   ```

5. commit & push，GitHub Pages 會自動更新。

送出後會自動建立兩個工作表：

| 工作表 | 內容 |
| --- | --- |
| 訂單總表 | 每筆訂單一列：時間、訂單編號、點餐家庭、品項摘要、總數量、總金額 |
| 訂單明細 | 每個品項一列：時間、訂單編號、點餐家庭、品名、單價、數量、小計 |

> 若之後修改了 `Code.gs`，要用 **部署 → 管理部署作業 → 編輯 → 版本：新版本** 才會生效。

## 修改菜單

編輯 `js/menu.js`。每個品項欄位：`id`、`cat`（分類）、`name`、`en`、`price`、選填 `img`（放在 `img/`）、`tag`（如 奶素／熱壺）、`note`。

## 本機預覽

```bash
python3 -m http.server 8080
# 開 http://localhost:8080
```
